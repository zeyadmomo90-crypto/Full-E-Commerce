# 🛒 Full E-Commerce Flutter App

A full-featured **E-Commerce mobile application built with Flutter** that allows users to browse products, view details, add items to the cart, and manage orders.

This project demonstrates Flutter development concepts such as API integration, UI design, navigation, and state handling.

---

## 📱 Features

* 🔐 User Authentication (Login / Register)
* 🏠 Home Screen with Product Listings
* 🔎 Product Details Page
* 🛒 Add to Cart Functionality
* 📦 Cart Management
* 👤 User Account
* 📡 API Integration
* 📱 Responsive UI for mobile devices

---

## 🛠 Tech Stack

* **Flutter**
* **Dart**
* **REST API**
* **DIO Requests**
* **Material UI**

---

## 📂 Project Structure

```
lib
│
├── models        # Data models (Product, User, etc.)
├── screens       # App screens (Login, Home, Product, Cart)
├── widgets       # Reusable UI widgets
├── services      # API and backend communication
└── main.dart     # Application entry point
```

## 🚀 Getting Started

### 1️⃣ Clone the repository

```
git clone https://github.com/zeyadmomo90-crypto/Full-E-Commerce.git
```

### 2️⃣ Navigate to the project folder

```
cd Full-E-Commerce
```

### 3️⃣ Install dependencies

```
flutter pub get
```

### 4️⃣ Run the app

```
flutter run
```
